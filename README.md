# lolalytics-persist

A lightweight browser extension and userscript that automatically saves and restores your [Lolalytics](https://lolalytics.com) preferences.

## Features

- Persist rank, tier, patch, and region.
- Support rolling periods (Last 7, 14, and 30 Days).
- Automatically restore preferences across pages.
- Support Chrome, Brave, and Firefox.
- Install as a browser extension or userscript.

## Installation

### Userscript

Install [Tampermonkey](https://www.tampermonkey.net/) or another compatible userscript manager, then install `lolalytics-persist.user.js`.

### Browser Extension

Load the `extension/` directory as an unpacked extension through your browser's extension settings.
